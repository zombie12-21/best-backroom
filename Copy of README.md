# BACKROOMS — play on GitHub Pages

1. Push this folder to a repo (root of repo or `/docs`).
2. Repo Settings → Pages → Deploy from branch → `main` + `/ (root)` (or `/docs`).
3. Open the Pages URL. Saves use localStorage, no server needed.
   (Online-player dots need Perchance's server-plugin, so they stay empty here.)

- Play: `index.html` + `src/`
- Perchance source backup: `perchance-main.pjs`, `perchance-index.html`
